# sports-sport-sports-

A simple real-time sports event prediction dashboard prototype.

## What this project does

This app simulates live sports match predictions and displays:

- a matchup between two teams
- projected score
- win probabilities
- confidence level
- automatic refresh for a live dashboard feel

## Stack

- Python 3
- Flask
- HTML/CSS/JavaScript

## Run locally

1. Create a virtual environment:
   python -m venv .venv
2. Activate it:
   - macOS/Linux: source .venv/bin/activate
   - Windows: .venv\Scripts\activate
3. Install dependencies:
   pip install -r requirements.txt
4. Start the app:
   python app.py
5. Open:
   http://localhost:5000

## Notes

This is an MVP starter for a real-time event prediction product. It can be extended with:

- real sports APIs
- ML-based scoring
- user authentication
- database storage
- live notifications
